# Security policy

## Reporting a vulnerability

Please do not report security problems in public issues or pull requests. Use GitHub's [private vulnerability reporting](https://github.com/otnc/astro-adapter-cloudflare-pages/security/advisories/new) instead.

A useful report includes:

- what the problem is and what an attacker could do with it
- steps to reproduce, ideally with a minimal Astro project
- the versions of this adapter, Astro, and Wrangler or `cf`

You will get a reply as soon as possible. Please keep the details private until a fix is released.

## Supported versions

Only the latest release receives security fixes.

## Scope

In scope: the code in this repository and the published `astro-adapter-cloudflare-pages` package, including the bundled agent skills.

Out of scope: vulnerabilities in Astro, Cloudflare Pages, Wrangler, or the `cf` CLI themselves. Report those to their maintainers.
